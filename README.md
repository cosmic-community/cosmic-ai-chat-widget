# Cosmic AI Chat Widget

A modern, AI-powered chat widget system built with Next.js 15, Cosmic CMS, and OpenAI. Perfect for adding intelligent customer support to any website.

## Features

- 🤖 **AI-Powered Responses** - Automatic intelligent replies using OpenAI
- 💬 **Real-time Chat** - Seamless conversation management
- 👥 **Team Dashboard** - Manage conversations and respond to visitors
- 🎨 **Customizable Widget** - Match your brand colors and messaging
- 📧 **Email Notifications** - Get notified of new conversations
- 🔐 **Secure Authentication** - Protected team dashboard
- 📱 **Responsive Design** - Works on all devices

## Quick Start

### Prerequisites

- Node.js 18+ or Bun
- A [Cosmic](https://cosmicjs.com) account
- An [OpenAI API key](https://platform.openai.com/api-keys)
